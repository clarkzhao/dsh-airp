## 1. 世界基调 / 时代 / 地理

- **世界名**：大荒（山海界）。上古为天帝—天神时代；颛顼帝命重与黎「绝地天通」后，神怪异兽渐绝迹，但天帝仍行走人间兼做人皇（尧舜禹），直至夏后启称人皇，再无天帝传闻。所有武学皆源于此前的天帝/天神传承或「食神怪异兽」所得特性。
- **历史是错位的**（蝴蝶晓梦）：夏（千年）→ 有穷代夏（约六百年，末二百年类春秋）→ 群雄争霸四百余年（百家争鸣，圣人左氏创儒、道）→ 秦（始皇一统，二百余载）→ 汉（八百年）→ 三国 → 魏（不足三百年）→ 天下大乱 → 大赵。诗词、朝代名似曾相识却重新组合；与地球诗人作者重合者仅「李白」（东汉诗仙、善剑、率兵攻至西海封汉侯）。[GM] 疑似异世来客：道安（西汉创佛门本有宗，后分裂为唯识/律宗/禅宗/身意等）、圣人左氏（兵→儒→道、编《诗经》、弃本名）、秦少游（魏词大家、为魏相）；丁松言推其出现间隔有规律、与天庭/天帝行宫/昆仑相关，魔君或为穿越成两面族者、在等「下一个穿越者」。纪年以夏后启继人皇位为元年（当前约四千余年）。
- **大赵**：皇室自称祝融后裔，姓洪，修火神一系功法（练到高深处「火气」大）。近二百六十年前异族叛乱（大人、周饶、三身、三首、靖人、君子、寿麻、犬戎），北方崩成三强国：新虞（三身/寿麻/靖人，帝舜后裔）、甘（大人/君子/周饶）、封（三首/犬戎/戎）；另有巴、天毒在边荒。百族另有**两面族**（一张脸敦厚、一张脸凶狠自私，前者是后者伪装；与两面族相处日久者脑后亦生第二张脸；各势力纳新必查后脑，防其混入）、**枭阳**（巨猿状、近丈高、嘴唇夸大、脚跟朝前，嗜吃人、力比三品入化；过于蠢笨，武林视为未开化巨猿，非精非怪非妖——不被镇妖祛邪克制，民间误传为山精；破绽：见人笑则己亦笑、唇翻覆额遮目，可诱其短暂失明；重伤时依野性夺路而逃）。两面族史：魏末赵初作恶，大赵立国后明正典刑杀其七八，余者圈禁帝阙山下小城、不许接触别族；南渡时逃出、隐入人群不知所踪。**氐人**（人面鱼身有足，百族之一，《秘传山海经》注「妖类龙属」——既百族又妖类；绝地天通前在建木西、能上下天地，亦寻天界；大赵有秘密水师以氏人为主，甘虞封亦有）。赵南渡偏安，都炎京；先皇成祖文皇帝与顶尖宗门和解，当今年号「建武」，锐意收复故土。
- **切片城市**：宁州·定江府（府治临江县），大江之畔，支流水车作坊连片。关键地点：城余巷（丁家）、当康庙（正殿供猪形当康神像；庙祝有猪状大耳、凸腹、长尖牙，近宗师异状；庙祝一系传耕种积肥、祈福说穰调和天象，属「人教/人道」一支——无教义经文、非道非佛而助人世人族者皆可算入，重术重德不重武；庙祝积福分可消耗以求「福缘」、遇能帮忙之人；庙前大市集，说书人聚集，文武买卖分区）、北水街（甄府）、丰水桥（夜集，灯如昼：三更方散；附近幽冥异常可外溢为报官案件，如停殡诈尸）、宝平巷（奇股人曲三郎）、隆兴街（延年医馆）、北里坊红袖街（歌楼花酒）、天阳会馆（小青居所）、望天门岛（江心，绝地天通后曾能见天界景象；有历代寻天界者所留草庐石窟——寻昆仑客同类，皆欲绕过绝地天通飞升天界；可见天界景象的上古之地共七八处，已知还有白水神仙谷、东海长青岛、甘国乾州帝阙山〔曾圈禁两面族〕、岳江府仙洞山〔天湖因此得名，或有魔君出没〕）、乱葬岗（城外，城墙望楼可视，后山不可见；去乱葬岗途中有座神像残缺的破庙——前身殒命处）、养济院（官府收留鳏寡孤独、病残）、慈幼局（收养孤儿弃儿，与官办武学相连，天子亲卫多出于此）。**彩船飞车**（机巧司机关造物）：楼船形三层+甲板、金铁翅膀+桨叶喷气，约十丈长；造价高昂——拥有者只得机巧司、兵部与顶尖势力；三品以上重臣可请、宗门须申请（有侍中斡旋可加速）；配飞行武者护持；申请须报乘员（防窃密）。**飞行的门槛**：大衍中期即飞者靠飞行特质（飞鼠/龙鱼），寻常武者须虚空凝窍成翅（速度不快），灵台境无相应特质亦飞不了。熊、屈、潘三姓为**噎**之后裔（噎乃黎下地所生；颛顼绝地天通「重托天、黎陷地」）；寿尽老怪物疑三姓藏「黎陷地」之秘、趁百族叛乱灭门夺功而无所获——潘家（潘云舟）即其后人。定江府不设宵禁，仅夜闭城门。城中木石高塔三鼓后顶部窜火，是全城报警。鸣金示警，击鼓关城门。百姓见怪不怪：不是纵兵乱城或宗师以上激斗，躲到街边即可。水门/水口有叶刃机关，无金刚不坏勿水遁出城。府衙不许城中用木鸢。
- **望楼 = 武道版监控**：每城多座（定江府城内五座），县衙/府衙/本地宗门轮值远望，监察「以武乱禁」与来犯之敌。在望楼注视下，光天化日几乎无人敢杀人——这是市井安全的边界。但望楼只震慑想留退路之人，拦不住抱着必死之心的亡命徒；不涉以武乱禁的追逐与私下争斗，望楼不管。被望楼锁定者常有「如针刺背」的预感。**望楼的盲区：城外驿站**——驿长兵卒记不住海捕文书肖像、匀不出专人比对，册簿上报县府一来一回数日，左道妖人只要外形不特别、非刚在附近犯案，都敢住店；荒郊商队在无人监管处亦可兼职盗匪。
- **基调**：武道昌盛 + 商品经济发达 + 医术惊人（开腹缝合、金针察魂、水激扇车、玻璃为奢侈品）+ 汉服形制混杂 + 夏日市井烟火。危险藏在「以武乱禁、帮派争斗、邪道妖人、身怀利器」里。

## 2. 力量体系（各是什么 / 谁能用 / 代价）

- **境界链**：初境（锻体、练气，亦称凡境）→ 生境（凝炼人体窍穴；下三品：窥径/登堂/入室 ≈ 民间九/八/七品，合称人境）→ 大衍境（造窍；四品：异人/勘玄/超凡/入化 ≈ 六/五/四/三品）→ 法境（宗师，分入微/通神）→ 天人境（大宗师）→ 灵台境（至人）。俗语：宗师镇一府，天人护一州，至人佑一国；天下约十四至人（正十邪四）。「四十岁不成宗师终生无望」；大宗弟子为避影响身体成长，多到十八岁后才完成锻体练气、开始炼窍，二十岁起步尚不算晚；入大衍境寿元有增，异人有望盗神药延寿百载以上。粗算：大衍+法境共约一甲子（大衍三成半）；法境 120–150，天人 200–210，灵台约 270。心性五阶：守一（初/人境）→ 明心（大衍）→ 不惑（法境）→ 玄同（天人）→ 逍遥（灵台）。「烛心」与烛照契合则无需游历也能明心，造窍可更频。练到高处，身体向功法源流的神怪异兽靠拢（虎耳、金羽、青皮、牛角、狐尾、重瞳、犬耳……），**看见身有异状者＝异族或高手**。异状可刻意遮掩（如犬耳贴头皮、以长发覆盖），但日常维持不易，松懈、破戒（如破色戒）时易露破绽；[GM] 亦有高手借功法/「气」为他人遮掩异状。
- **魂相**：三魂七魄与肉身的对应。受惊过度或伤魂功法可令魂魄离散，归体后「魂相不符」→ 失忆；魂魄受损则三魂有缺七魄不全（痴傻或卧床）。药王派「金针察魂」可验契合与否——**夺舍者未必瞒得过金针**（丁松言魂相契合是例外，GM 可作伏笔）。**夺舍有天罚**：夺舍（泯灭原主魂魄）违背正道门规且遭天罚——夺舍之际天降「如烟黑暗+幽绿阴雷」直劈神魂；夺舍秘法可压制镇妖祛邪（神魂化赤红流光强闯他人识海）。《玄关藏性历劫不昧大法》三用：轮回转世、灌输传法、夺舍重生。夺舍把真气化本源寄身外虚相，约一年半载反哺改造躯体；不过冥界诸劫与胎中劫，只过识海劫——失败则与庐主融合迷失，或痴傻，或自认得了离魂症。须性与命皆契合、神魂显著弱于自身。
- **变化之术**：绝地天通后，妖类已无法化形成人。平日维持人形、仅偶现兽身（如蛇尾），是「天人境大宗师」或少数擅长变化的功法（如《天狐经》）方能做到——**看见半人半兽者，不是大宗师，就是特殊功法传人**。
- **识海**：神魂之海（虚幻汪洋）。高手可在他人识海植入「气/种子」，妙用：在眼破妄、在手伤人、在脚腾跃、在魂护身；也能**无形影响思绪**——让人忘记该做的事、引导其行为（非读心，是灌注意图）。明面「种子」用尽后，暗线仍可能继续让人「忘记报官」。**气不提升境界、眼力、反应与实战本能**，只提供单次妙用；被动挨打时来不及换招。种子是预设规避名单，不是实时监察——可把一件不能说的事拆成数日、数个侧面，由对方自行拼凑。此类影响只能压制/隐藏记忆，不能抹除——离开对应场景、换话题后，被压住的记忆会翻涌回来。识海可被读心/搜魂，需功法守护。读心类功法例「镜湖神鉴」（映照心湖、闻听念头，须一丈内；识海有幽暗遮掩者听不到；可用天心印记心神一分为二，一边守心一边行事）。入梦术「大梦三千载」（黄粱宗）：入他人梦境、引导其梦中行事，受害者误认梦游，醒后记忆清晰以为真事；精神覆盖约三十丈、仅触及梦境。附「御凶御邪」——御邪可与镇妖祛邪融合，御凶防凶险（有额度，挡不住不直接带来凶险的影响）；「以身化魇」可搏杀中直接用（令对手见最恐惧幻境，知心灵破绽则效果更佳）。醒木（黄粱一梦桃木枕所制）：入梦经历世事、明悟至理；亦可暗藏梦境剑意——抛出诱敌、被夺后引动扰神（神物自晦）。黄粱真气只能与有无万象气并存，无法与烛明真气并存（故难以融入烛照剑意）。害人三法：**梦中杀人**（惊恐害魂）、**梦中诱导**（潜移默化）、**梦中致病**（夜复一夜梦到同一种病→现实病亡，最隐蔽难察——官府对策：连续做同样或类似之梦者须报衙门）；可一次入梦多人、令目标梦中保持清醒交流、顺精神联系反追踪；梦中身死则现实随亡。法境真版可侵袭识海、令目标念头随己意上演（经历一生=黄粱一梦）、可修改删增念头（令人崩溃或大彻大悟）——须目标沉睡、施展时不能同时攻击。
- **烛照**：宵明、烛光两位女神传承（宵明宗），根本大法《周天星斗书》《烛照长夜经》（法境后段已遗失）。特质「星之光、烛之火、照长夜、洞幽邃」：**克阴邪与心控**。郑朱曦修出大衍境稀有「烛照剑意」（同门多要到入化才练得出），借剑意盘桓他人膻中（绛宫）三日，可洞察髓海、挡一次蛾种/巫蛊/心控引导。亦可驱散附身精怪（阴眼可见扭曲如蛇的黑影）。亦可借灯火（玻璃宫灯）照入他人识海，令阴暗念头退去、心控「种子」下沉躲藏。**压制强度随施术者境界递增**：大衍「异人」境仅能令边缘限制松动，宗师境方可能令其临时摆脱。烛眼星瞳：烛明推「烛眼」破妄，万星推「星瞳」望远，皆夜明洞幽勘幻。两经篇章以强行记成本能习练耗寿（炼窍篇各约八年、大衍/法境篇预计各八年）。
- **破妄**：借「气」或剑意催发破妄之眼——辨伪装、察阴邪、看穿蛾种控制痕迹（朱蛾触须）。有生效时限与消耗；须交叉验证，防被附加幻觉误导。
- **修行之「骗」**：修行第一诀窍是**先骗自身神魂**——存神凝思、观想图谱（临大日、坠冰窟、见鬼神），意在气先，神魂先行带动身躯变化，久成永久影响。严长青秘法口诀「骗人先骗己，假能成真，信之则有」：可加速锻体练气、加速恢复（休三时辰抵六时辰）；亦可把观想凝炼强行记成本能（耗寿，只宜用在本门真气）。**代价：消耗元气、减损寿数**（入大衍后可补回）。秘法非功法，须配一门武功同修，否则身患癔症、疯疯癫癫。以骗入剑：骗局要前置，时机对了假能变真。其背后是「人为贵」根本论：人为万灵之长、百族之首，长处在于智慧、精神、灵台，练武先练「神」、修行先修「己」——帝轩辕合道后、夏后启前，天帝必兼为人皇。此秘法亦可反向利用：以自我欺骗骗过识海「种子」的念头监察（种子按「自由心证」屏蔽泄密/恶意意图，假装「并无泄露之意」即可过关，除非施术者就近实时监察）。
- **蛾种**：源自封国蛾神宗（朱蛾/蚍蜉传承；《秘传山海经》：「朱蛾，蚍蜉也，其状如蛾……食之使百虫、同髓海、千人一面」）。朱蛾形似红色大蚂蚁的飞蛾，自耳洞出入；被蛾种控制者为「蛾人」。机制：蛾父/蛾母须在百丈内掌控，越近越灵，十丈内蛾人可如常用武功、能交谈；**蛾人话多、有自我意识 = 异状（或有隐情）**——常因识海另植天心「种子」，一加一大于二。蛾人宿主身亡后，蛾种会自口鼻蹿出，随即自行裂解；蛾种本体脆弱，被外力抓住捏碎即灭。死者尸体较头部更快腐臭 → 大赵武禁司列嫌疑：五贼门/蕈人派/千傀门/蛾神宗。
- **造窍**：人境→大衍的分野，也是「转修不可逆」的根源。人族与神怪异兽窍穴不同，凝完人体窍穴后须**无中生有生造异类窍穴**：针引、药注（阴尸草、鬼王草、血砂等资粮），复杂的开膛破肚、植入奇金异铜。最简法：资粮化开 + 中空银针刺穴 + 导液入体（鬼王草至阴开纯阳花，血砂至阳内生阴寒水，可配对）。更复杂有体外造窍、植入血肉（例「倏忽」：阳帝铜+归山玉制赤金圆球、孔内玉粉，柳叶刀开半寸深伤口、真气兜血，植入后逐层连接血肉经脉、导血融合，窍穴由实转虚与身魂相融，羊肠线缝合）。**造窍时多不用麻醉**——须亲身感受调整真气线路（普通弟子可麻醉、传功长老引导）。肢体残缺危及重要窍穴→境界倒退、法境无望；次重要者顶多实力有损；**成宗师后可在体外虚空补造缺失窍穴**。每门功法造窍法不同，且造窍法与凝炼法常分离（传功长老掌握，防外泄）。正常一月一窍算骄子。人境炼窍通常约两年（一年半至三年）；浑沌系功法窍穴极多（人境六至九年、异类窍穴一百零八），耗时是软肋，但熬过者心性足，或可较快入法境。造窍后休养视法门一两日到十余日；装脏后须半月甚至一月（宵明宗不成文规矩：**每年至少装脏三次**，防不可逆损伤；休养期由仆役日夜照顾）；装脏后须分次运转真气穿行新脏（每次间隔至少两刻钟、首次由传功长老引导）；**首次装脏后宗门必安排一次游历**（适应身体、锤炼心性、增搏杀经验——在外无法造窍）。**装脏顺序各派不同**（《烛照长夜经》：朱雀→白虎→玄武→青龙；《周天星斗书》：青龙→朱雀→白虎→玄武）。**大衍境初/中/后划分因功法造窍装脏顺序而乱**——「圆满」统一（全部造窍+装脏+凝脉），各派标准不一（宵明：首次装脏前=初期、一二两次装脏=中期、三次装脏毕=后期）。**费用体系**：大宗门造窍装脏免费但评估心性身体、资粮有限按贡献天赋排队；造窍资粮一般一两种（不罕见者不贵，《周天星斗书》异类窍穴平均七十两一处）；装脏除需「一金」的**白虎**（千两至八千两）外其余三种平均八百两一种；散修须自筹资粮+雇可信医师（如开腹装脏的「外科」）。**窍穴冲突**：两门功法所需窍穴重合→走火入魔/武功全废/疯癫/亡故；无重合可兼修转修；蛟蛇之学可被真龙之学包容转化。法境与大衍的分野 = **虚空凝窍**（神游身周、感天应地，在身外虚空某处造窍）。虚空窍穴不仅对应异类窍穴放不下之部分，还有原本就存在于虚空者——神怪异兽影响天地亦自虚空窍穴始。法境大成可覆身周十丈以上（星空加持、泽国溺感、火海幻象），尚未完整化虚为实；真焰/真水往往只在兵器与体表。大衍境还有「装脏」（青龙/白虎/朱雀/玄武等非人内脏，合二十八宿格局）。散修/武馆弟子的现实瓶颈：炼窍大成后须以银钱购后续法门、自行筹集造窍资粮，无门无派者多卡在人境门前蹉跎。
- **剑与剑意**：剑非独立体系，是功法的「用」。宵明宗有北斗剑阵（七人）、天罡剑阵（三十六人；以两位宗师为阵眼、辅以大衍境出类拔萃者，可逼退天人境大宗师）；**星辰暗语**：结合人体窍穴将方位标以星名（紫微=正下方、左弼=左斜下、女士蝠=斜上方……），报星名即知攻向何处，是两阵前置本能。寒影剑（陶问书所赐，曲中横铸）：昆吾铜+龙首铁+北冥冰精+定江锻钢，四尺三寸，晶莹含赤红薪火，走「冬」，宙光生乱（快慢），天人以上或可冻宙光须臾。郑朱曦之剑「秋水」（秋）。入门剑「破晓」三十六式；炼窍有成生万星真气才可留气于腕化虚为实。以「骗」入剑：先铺垫让对手把某变当虚招，时机对了假变真。搏杀两极：「以我为主」一剑破万法，「以他为主」专打破绽习惯。剑有灵：如臂使指、鞘中轻鸣示警、可伤恶鬼；养灵非一时，刻名须子时开阴眼看天地气。**剑意**：无法杀人，却能影响目标的意和神，可存于他人识海或绛宫内一段时日，克制「天心印记」；大衍境武者须心性契合功法且剑心明照方能凝意于剑（宗师可神意气三合轻易衍化）。以身化魇可融入剑意成「魇剑」（梦魇困敌，烛照可破）与「梦剑」（伪造宿世轮回，用目标熟悉的故事制造既视感，是骗术非真轮回；遇类似功法谨守自身）。遮掩异状可瞒同境，瞒不过独特功法或熟人。无外表异状：要么普通，要么很强（异人阶段多未显）。

## 6. 公理（axioms，4–8 条，常驻、不剧透后期）

1. 天下武学皆出自绝地天通前的天帝天神传承，或「食神怪异兽」所得；练到高处，身体会向源流异状靠拢——**看见身有异状者，不是异族，就是高手**。
2. 窍穴定命：生境之后凝窍/造窍不可乱来——两门功法所需窍穴重合即冲突（走火入魔、武功全废、疯癫或亡故）；无重合方可兼修转修；蛟蛇之学可被真龙之学包容转化。
3. 自「有穷替夏」，各国朝廷与宗门销毁、私藏《秘传山海经》；**非大宗大派弟子持之必被追杀**。吃神物可一步登天，也一步踏入杀身之祸。
4. 望楼在，法在：每城望楼由朝廷与本地宗门轮值远望，监察以武乱禁；光天化日之下，没人敢在望楼注视下杀人。
5. 阴阳相隔：孤魂野鬼无灵智、害不了人；但相隔并非绝对——阴眼可窥幽冥，特殊者能以手掌触阴间之物，代价是精神与阴气侵蚀。
6. 言语与心灵皆是战场：高手可借「气」或术数影响他人思绪、窥破秘事；宵明/烛照一系的「洞幽邃」之光可照破阴邪与心控。谨防被引导着忘记、被引导着行动。

## 8. 鉴定规则建议（3 个 check，照《DSH-AIRP 引擎方案》§5 声明式写法）

### 8.1 contest-wushu（对抗）
```yaml
id: contest-wushu
when: 武者直接对抗（帮派火并、蛾人袭击、以武犯禁）
kind: contest
condition:
  all:
    - tag: contest
    - present: ["$attacker", "$defender"]
inputs:
  atk: characters.{attacker}.grade        # 品级数字，越大越弱（0=凡境/未入品）
  def: characters.{defender}.grade
  atk_skill: characters.{attacker}.skill  # 特技/心机修正（±）
  def_skill: characters.{defender}.skill
formula: |
  strength = def - atk + (atk_skill - def_skill)
  p = sigmoid(-strength / 1.5)
outcomes:
  success:
    apply:
      facts.last_contest: attacker
  failure:
    apply:
      facts.last_contest: defender
      characters.{attacker}.cost: "+0.15"   # 伤/代价，走 check 通道
```
注：`grade` 语义与廷根 `sequence` 一致（数字越大越弱），formula 可整体复用。

### 8.2 powang-zhuozhao（破妄 / 烛照）
```yaml
id: powang-zhuozhao
when: 主动破妄或烛照（鉴别阴尸草真伪、看破伪装/蛾种、开阴眼窥幽冥）
kind: insight
condition:
  tag: powang
inputs:
  insight: characters.{actor}.insight  # 识海清明 0–1
  candle: characters.{actor}.candle    # 烛照进度 0–1
formula: |
  p = clamp(0.35 + insight * 0.25 + candle * 0.3)
outcomes:
  success:
    apply:
      facts.revealed_truth: true
  failure:
    apply:
      facts.revealed_truth: false
      facts.misjudged: true
```

### 8.3 ruju-cost（入局代价 / 消化）
```yaml
id: ruju-cost
when: 接触邪异并付代价（触碰幽冥之物/阴尸草、被蛾种近身、透支本源）
kind: cost
condition:
  tag: cost
inputs:
  moth: characters.{actor}.moth  # 蛾种污染 0–1
  yin: characters.{actor}.yin    # 阴气侵蚀 0–1
formula: |
  p = clamp(1 - moth * 0.5 - yin * 0.5)
outcomes:
  success:
    apply:
      facts.held_together: true
  failure:
    apply:
      facts.held_together: false
      characters.{actor}.yin: "+0.15"
      characters.{actor}.moth: "+0.1"
```
