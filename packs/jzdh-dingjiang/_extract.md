## 1. 世界基调 / 时代 / 地理

- **世界名**：大荒（山海界）。上古为天帝—天神时代；颛顼帝命重与黎「绝地天通」后，神怪异兽渐绝迹，但天帝仍行走人间兼做人皇（尧舜禹），直至夏后启称人皇，再无天帝传闻。所有武学皆源于此前的天帝/天神传承或「食神怪异兽」所得特性。
- **历史是错位的**（蝴蝶晓梦）：夏（千年）→ 有穷代夏（约六百年，末二百年类春秋）→ 群雄争霸四百余年（百家争鸣，圣人左氏创儒、道）→ 秦（始皇一统，二百余载）→ 汉（八百年）→ 三国 → 魏（不足三百年）→ 天下大乱 → 大赵。诗词、朝代名似曾相识却重新组合。
- **大赵**：皇室自称祝融后裔，姓洪，修火神一系功法（练到高深处「火气」大）。近二百六十年前异族叛乱（大人、周饶、三身、三首、靖人、君子、寿麻、犬戎），北方崩成三强国：新虞（三身/寿麻/靖人，帝舜后裔）、甘（大人/君子/周饶）、封（三首/犬戎/戎）；另有巴、天毒在边荒。赵南渡偏安，都炎京；先皇成祖文皇帝与顶尖宗门和解，当今年号「建武」，锐意收复故土。
- **切片城市**：宁州·定江府（府治临江县），大江之畔，支流水车作坊连片。关键地点：城余巷（丁家）、当康庙（正殿供猪形当康神像；庙祝有猪状大耳、凸腹、长尖牙，近宗师异状；庙祝一系传耕种积肥、祈福说穰调和天象；庙前大市集，说书人聚集，文武买卖分区）、北水街（甄府）、丰水桥（夜集，灯如昼：三更方散，红、橘、粉、黄各色灯笼，痴男怨女水边放船型彩灯）、宝平巷（奇股人曲三郎）、隆兴街（延年医馆）、北里坊红袖街（歌楼花酒）、天阳会馆（小青居所）、望天门岛（江心，绝地天通后曾能见天界景象）、乱葬岗（城外，城墙望楼可视，后山不可见；去乱葬岗途中有座神像残缺的破庙——前身殒命处）、养济院（官府收留鳏寡孤独、病残）。定江府不设宵禁，仅夜闭城门。城中木石高塔三鼓后顶部窜火，是全城报警。鸣金示警，击鼓关城门。百姓见怪不怪：不是纵兵乱城或宗师以上激斗，躲到街边即可。
- **望楼 = 武道版监控**：每城多座（定江府城内五座），县衙/府衙/本地宗门轮值远望，监察「以武乱禁」与来犯之敌。在望楼注视下，光天化日几乎无人敢杀人——这是市井安全的边界。但望楼只震慑想留退路之人，拦不住抱着必死之心的亡命徒；不涉以武乱禁的追逐与私下争斗，望楼不管。被望楼锁定者常有「如针刺背」的预感。
- **基调**：武道昌盛 + 商品经济发达 + 医术惊人（开腹缝合、金针察魂、水激扇车、玻璃为奢侈品）+ 汉服形制混杂 + 夏日市井烟火。危险藏在「以武乱禁、帮派争斗、邪道妖人、身怀利器」里。

## 2. 力量体系（各是什么 / 谁能用 / 代价）

- **境界链**：初境（锻体、练气，亦称凡境）→ 生境（凝炼人体窍穴；下三品：窥径/登堂/入室 ≈ 民间九/八/七品，合称人境）→ 大衍境（造窍；四品：异人/勘玄/超凡/入化 ≈ 六/五/四/三品）→ 法境（宗师，分入微/通神）→ 天人境（大宗师）→ 灵台境（至人）。俗语：宗师镇一府，天人护一州，至人佑一国；天下约十四至人（正十邪四）。「四十岁不成宗师终生无望」；大宗弟子为避影响身体成长，多到十八岁后才完成锻体练气、开始炼窍，二十岁起步尚不算晚；入大衍境寿元有增，异人有望盗神药延寿百载以上。练到高处，身体向功法源流的神怪异兽靠拢（虎耳、金羽、青皮、牛角、狐尾、重瞳、犬耳……），**看见身有异状者＝异族或高手**。异状可刻意遮掩（如犬耳贴头皮、以长发覆盖），但日常维持不易，松懈、破戒（如破色戒）时易露破绽；[GM] 亦有高手借功法/「气」为他人遮掩异状。
- **魂相**：三魂七魄与肉身的对应。受惊过度或伤魂功法可令魂魄离散，归体后「魂相不符」→ 失忆；魂魄受损则三魂有缺七魄不全（痴傻或卧床）。药王派「金针察魂」可验契合与否——**夺舍者未必瞒得过金针**（丁松言魂相契合是例外，GM 可作伏笔）。
- **变化之术**：绝地天通后，妖类已无法化形成人。平日维持人形、仅偶现兽身（如蛇尾），是「天人境大宗师」或少数擅长变化的功法（如《天狐经》）方能做到——**看见半人半兽者，不是大宗师，就是特殊功法传人**。
- **识海**：神魂之海（虚幻汪洋）。高手可在他人识海植入「气/种子」，妙用：在眼破妄、在手伤人、在脚腾跃、在魂护身；也能**无形影响思绪**——让人忘记该做的事、引导其行为（非读心，是灌注意图）。明面「种子」用尽后，暗线仍可能继续让人「忘记报官」。**气不提升境界、眼力、反应与实战本能**，只提供单次妙用；被动挨打时来不及换招。种子是预设规避名单，不是实时监察——可把一件不能说的事拆成数日、数个侧面，由对方自行拼凑。此类影响只能压制/隐藏记忆，不能抹除——离开对应场景、换话题后，被压住的记忆会翻涌回来。识海可被读心/搜魂，需功法守护。
- **烛照**：宵明、烛光两位女神传承（宵明宗），根本大法《周天星斗书》《烛照长夜经》（法境后段已遗失）。特质「星之光、烛之火、照长夜、洞幽邃」：**克阴邪与心控**。郑朱曦修出大衍境稀有「烛照剑意」，借剑意盘桓他人膻中（绛宫）三日，可洞察髓海、挡一次蛾种/巫蛊/心控引导。亦可借灯火（玻璃宫灯）照入他人识海，令阴暗念头退去、心控「种子」下沉躲藏。**压制强度随施术者境界递增**：大衍「异人」境仅能令边缘限制松动，宗师境方可能令其临时摆脱。
- **破妄**：借「气」或剑意催发破妄之眼——辨伪装、察阴邪、看穿蛾种控制痕迹（朱蛾触须）。有生效时限与消耗；须交叉验证，防被附加幻觉误导。
- **修行之「骗」**：修行第一诀窍是**先骗自身神魂**——存神凝思、观想图谱（临大日、坠冰窟、见鬼神），意在气先，神魂先行带动身躯变化，久成永久影响。严长青秘法口诀「骗人先骗己，假能成真，信之则有」：可加速锻体练气、加速恢复（休三时辰抵六时辰）。**代价：消耗元气、减损寿数**（入大衍后可补回）。秘法非功法，须配一门武功同修，否则身患癔症、疯疯癫癫。其背后是「人为贵」根本论：人为万灵之长、百族之首，长处在于智慧、精神、灵台，练武先练「神」、修行先修「己」——帝轩辕合道后、夏后启前，天帝必兼为人皇。此秘法亦可反向利用：以自我欺骗骗过识海「种子」的念头监察（种子按「自由心证」屏蔽泄密/恶意意图，假装「并无泄露之意」即可过关，除非施术者就近实时监察）。
- **蛾种**：源自封国蛾神宗（朱蛾/蚍蜉传承；《秘传山海经》：「朱蛾，蚍蜉也，其状如蛾……食之使百虫、同髓海、千人一面」）。朱蛾形似红色大蚂蚁的飞蛾，自耳洞出入；被蛾种控制者为「蛾人」。机制：蛾父/蛾母须在百丈内掌控，越近越灵，十丈内蛾人可如常用武功、能交谈；**蛾人话多、有自我意识 = 异状（或有隐情）**——常因识海另植天心「种子」，一加一大于二。蛾人宿主身亡后，蛾种会自口鼻蹿出，随即自行裂解；蛾种本体脆弱，被外力抓住捏碎即灭。死者尸体较头部更快腐臭 → 大赵武禁司列嫌疑：五贼门/蕈人派/千傀门/蛾神宗。
- **造窍**：人境→大衍的分野，也是「转修不可逆」的根源。人族与神怪异兽窍穴不同，凝完人体窍穴后须**无中生有生造异类窍穴**：针引、药注（阴尸草、鬼王草、血砂等资粮），复杂的开膛破肚、植入奇金异铜；每门功法造窍法不同，且造窍法与凝炼法常分离（传功长老掌握，防外泄）。**窍穴冲突**：两门功法所需窍穴重合→走火入魔/武功全废/疯癫/亡故；无重合可兼修转修；蛟蛇之学可被真龙之学包容转化。法境与大衍的分野 = **虚空凝窍**（神游身周、感天应地，在身外虚空某处造窍）。大衍境还有「装脏」（青龙/白虎/朱雀/玄武等非人内脏，合二十八宿格局）。散修/武馆弟子的现实瓶颈：炼窍大成后须以银钱购后续法门、自行筹集造窍资粮，无门无派者多卡在人境门前蹉跎。
- **剑与剑意**：剑非独立体系，是功法的「用」。宵明宗有北斗剑阵（七人）、天罡剑阵（三十六人；以两位宗师为阵眼、辅以大衍境出类拔萃者，可逼退天人境大宗师）。寒影剑（陶问书所赐）：昆吾铜+龙首铁+北冥冰精+定江锻钢，削铁如泥、触者深寒、剑身晶莹带赤红薪火，走「冬」之意味，能于快慢上做文章（宙光生乱），未来可冻宙光；郑朱曦之剑名「秋水」（秋）。
- **幽冥**：阴曹地府仍在（后土「主宰幽冥」、西王母「通幽冥」）。孤魂野鬼无灵智无神通、怕阳气，三五日坠幽府或消散。阴眼（如奇股人眉心横眼，夜里开）：看天地之气流动、孤魂野鬼，造玄奇机关亦须深夜以阴眼为之。天生阴阳眼（白日阳眼、夜里阴眼）能常看幽冥。特殊者（如借尸还魂者）可得**不稳定阴阳眼**，借「气」催发：把「种子」移至眉心即开阴眼（不耗次数，约持续一盏茶）；**须阴眼开启后**再把种子移至掌心，方能以手掌触碰阴间之物（未开阴眼时种子在掌心只是伤人预备，不通幽冥）——把铜钱放入幽冥石柱风化洞中即成「阴阳钱」送入阴间，取出后染阴绿、阴寒虚幻。阴阳钱用途：懂对应功法者可于「招神役鬼」时使用；数量够多可作幽冥「买路钱」，不被恶鬼侵袭；须贴身携带、以血意阳气压住，否则招来不干净之物（大多害不了人，但走背字）。燃灵犀角可携人同览幽冥景象。把「种子」移至喉咙可发阴冷飘忽之音、与残魂鬼影交谈（残魂多只余执念，答非所问）。亡者头七前后，执念深者残魂或徘徊殒命处，阴眼可见、通语可谈。阴气死气浓郁之地（如乱葬岗后山）亦可自行触发不稳定阴眼。**代价：精神消耗与阴气侵蚀**。
- **衍道德**（[GM] 后期主角之力，作「神物」级条目即可，勿进公理）：最古天帝（黄帝）遗骸「浑沌」之力。道=先天之道、德=后天之德，合则「衍天地衍万物衍万法」：可借外物临摹衍化他法之变（弱两三分），识海覆幽暗可防读心搜魂，可包容《天心智慧经》等；但力量有消退时限（三五年），须在期限内走完武道路。
- **天心印记**（[GM]）：《天心智慧经》（绝圣道上九道）根本法「易天变地神功」衍化，把自身意图借天心灌注给目标、影响其行为，不读心；近身或深知目标效果最佳；可把「气」赠予他人。完整口诀：「以己心印天心，以天心注人心」。近身同房即可实时遮盖回忆。同门破妄看不破同门伪装。术数之道当面卜算可断婚丧祸福、身体、月内祸福；至人之下至多能断到「最近看的是话本/演义/秘籍」一类，算不出具体哪一本——「算出你看过某本书」多半是骗术+同伙，除非术者与那本书有关联。
- **无用神功**（真灵宗）：生前无用、死后为神。特质「招神役鬼」「精魂不灭」。第一次死直接升一大境界并获强能；再死看境界（法境圆满/天人圆满各再一次），后几次只升小境或增强实力。修到天人就会因各种缘由死去，从未死后破入玄境。死前有杀劫，旁人宜躲远。死后金光可凝甲冠剑，可抚面抽神魂再以金剑劈之。
- **《秘传山海经》**：据传抄自天帝遗书《帝注山海经》（昆仑已消失）。昔年昆仑帝宫《帝注山海经》分刻各殿玉板，帝宫倾覆时在场者各记下一部分（有记错者），故各家私藏皆不完整，江湖流传者更是宗门衰败后外泄的残卷——**没有哪家有完整版**。记录天帝、天神、神怪异兽特性与「食之」效果（帝=五段描述、次一级=四段、三/两段……）；「食之」可获神通甚至一步登天（风亦宁吞凤凰卵，十六岁宗师）。已知条目示例：烛龙（开浑沌、照九阴、掌昼夜）、青丘狐/天狐（无蛊患、变万千、魅天下）、应龙（呼风雨、驭雷霆，龙祖凤始）、离朱（察秋毫末、见万里外）、蜮/蜮祖（含沙射人、伤影及体）、涉橐（司方正、具光明）、絜钩（携五瘟）、饕餮（吞天食地）、凤凰（号百鸟）、祝融（火之神、赤帝之佐）、何罗鱼（食之十命、百手、无咎；一首十身，其音如犬）、孰湖（马身鸟翼、人面蛇尾，食之力胜百牛、神行万里、感天知人）……**果实、树木、草药类神物与纯治病异怪不干扰任何功法修炼**（如瑶姬所化䔄草「服之媚于人」、櫰果「食之多力」）；食神怪异兽之躯则须与自身功法讲克制（蛊虫类忌鸟肥遗、九尾狐传承，疫病类忌鸟肥遗，凤凰号令百鸟）。自「有穷替夏」被各朝廷宗门销毁私藏；**非大派弟子持有必被追杀**。对高手是「鉴别神物、知己知彼」的至宝；对人族而言吃错神物或有性命之危。**分量**：只吃精髓处即可，多吃无益甚至爆体、凶气入脑、神意夺躯；分量不足则得一年半载到十余年不等的法境圆满，期限内摸清炼窍/造窍与所需天材则可把境界坐实，否则期满跌回只剩少许神异。吃到法境圆满后再往天人，仍须自身心灵与天地感悟——芝兰谱不纳大宗师，不是人少，是它不配。吃神物时精神与身躯同步增强，故短期不似炼窍那般易走火，但仍会残留神兽意念，日后须锤炼心灵。自汉末以来，纯靠吃神物更难证天人——神异衰减补不了根本之弱，如此而为的宗师十之七八困于法境。

## 3. 社会与门阀

- **朝廷**：大赵偏安江南，年号建武。玉书之盟（有穷一朝始）：名门正派、世家大族可「减钱粮，监刑狱，协理巡防」——宗门即地方治安共治者（定江府及北三县归宵明宗）。望楼轮值、武禁司（炎京，管异族功法异常）。县衙有书办、捕快（薛仗剑，身意异宗俗家弟子）、县尉羿秦苍（羿姓直系，「射日九箭」；定品「入化」四品，居高而射可挡入微宗师）。帮派之争可向衙门「报备」，报备成功即默许火并见血（须不涉无关人等、不在大庭广众以武乱禁）。邪道界定：以天下大乱为己任、以散播灾祸为乐趣、功法血腥残忍者皆为邪道，诸国皆缉捕，但亦有国家暗与邪道合作。**有大宗师坐镇，方称顶尖宗门或世家大族**。

## 6. 公理（axioms，4–8 条，常驻、不剧透后期）

1. 天下武学皆出自绝地天通前的天帝天神传承，或「食神怪异兽」所得；练到高处，身体会向源流异状靠拢——**看见身有异状者，不是异族，就是高手**。
2. 窍穴定命：生境之后凝窍/造窍不可乱来——两门功法所需窍穴重合即冲突（走火入魔、武功全废、疯癫或亡故）；无重合方可兼修转修；蛟蛇之学可被真龙之学包容转化。
3. 自「有穷替夏」，各国朝廷与宗门销毁、私藏《秘传山海经》；**非大宗大派弟子持之必被追杀**。吃神物可一步登天，也一步踏入杀身之祸。
4. 望楼在，法在：每城望楼由朝廷与本地宗门轮值远望，监察以武乱禁；光天化日之下，没人敢在望楼注视下杀人。
5. 阴阳相隔：孤魂野鬼无灵智、害不了人；但相隔并非绝对——阴眼可窥幽冥，特殊者能以手掌触阴间之物，代价是精神与阴气侵蚀。
6. 言语与心灵皆是战场：高手可借「气」或术数影响他人思绪、窥破秘事；宵明/烛照一系的「洞幽邃」之光可照破阴邪与心控。谨防被引导着忘记、被引导着行动。

## 8. 鉴定规则建议（3 个 check，照《DSH-AIRP 引擎方案》§5 声明式写法）

### 8.1 contest-wushu（对抗）
```yaml
id: contest-wushu
when: 武者直接对抗（帮派火并、蛾人袭击、以武犯禁）
kind: contest
condition:
  all:
    - tag: contest
    - present: ["$attacker", "$defender"]
inputs:
  atk: characters.{attacker}.grade        # 品级数字，越大越弱（0=凡境/未入品）
  def: characters.{defender}.grade
  atk_skill: characters.{attacker}.skill  # 特技/心机修正（±）
  def_skill: characters.{defender}.skill
formula: |
  strength = def - atk + (atk_skill - def_skill)
  p = sigmoid(-strength / 1.5)
outcomes:
  success:
    apply:
      facts.last_contest: attacker
  failure:
    apply:
      facts.last_contest: defender
      characters.{attacker}.cost: "+0.15"   # 伤/代价，走 check 通道
```
注：`grade` 语义与廷根 `sequence` 一致（数字越大越弱），formula 可整体复用。

### 8.2 powang-zhuozhao（破妄 / 烛照）
```yaml
id: powang-zhuozhao
when: 主动破妄或烛照（鉴别阴尸草真伪、看破伪装/蛾种、开阴眼窥幽冥）
kind: insight
condition:
  tag: powang
inputs:
  insight: characters.{actor}.insight  # 识海清明 0–1
  candle: characters.{actor}.candle    # 烛照进度 0–1
formula: |
  p = clamp(0.35 + insight * 0.25 + candle * 0.3)
outcomes:
  success:
    apply:
      facts.revealed_truth: true
  failure:
    apply:
      facts.revealed_truth: false
      facts.misjudged: true
```

### 8.3 ruju-cost（入局代价 / 消化）
```yaml
id: ruju-cost
when: 接触邪异并付代价（触碰幽冥之物/阴尸草、被蛾种近身、透支本源）
kind: cost
condition:
  tag: cost
inputs:
  moth: characters.{actor}.moth  # 蛾种污染 0–1
  yin: characters.{actor}.yin    # 阴气侵蚀 0–1
formula: |
  p = clamp(1 - moth * 0.5 - yin * 0.5)
outcomes:
  success:
    apply:
      facts.held_together: true
  failure:
    apply:
      facts.held_together: false
      characters.{actor}.yin: "+0.15"
      characters.{actor}.moth: "+0.1"
```
