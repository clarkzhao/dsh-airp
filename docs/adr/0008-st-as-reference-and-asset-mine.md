# ADR-0008：SillyTavern 降为参考实现与资产矿，运行时宿主改为 DSH

- 状态：Accepted
- 日期：2026-08-18
- 决策者：clark（Q1-C）
- 取代：ADR-0001 / 0002 / 0004 / 0005 中「双轨且 A 保 ST 运行时」的产品定位（这些 ADR 保留为历史，不再指导实现）

## 背景

2026-08-16 将路线 A（原装 ST + DSH 管家）与路线 B（Cordis 原生叙事内核）并列为双轨。2026-08-18 的判断是：ST 缺的是独立鉴定层和诚实的状态转移 T→T+1，不是缺一份诡秘世界书。继续养 ST 宿主不能补上这两块。

## 决策

1. **运行时只有 DSH**（web profile + AIRP 插件 + 两个产品 preset）。
2. **ST 仓库只当对照代码**：世界书激活、宏、角色卡字段用来说明「不要复刻什么」。
3. **ST 用户数据是资产矿**：角色卡 / 世界书 / 聊天由日后的 `story-import` agent 做语义转写，不保证格式兼容（仍遵守 D1）。
4. **不再做** ST 安装器、管家面板、兼容矩阵执行、ST 进程内扩展。

## 后果

- 失去「老用户 data 目录原样迁移且扩展零修改运行」这条 DoD。
- 获得单一热路径：鉴定与叙述都在 DSH agent loop 里，状态事件可进同一条 session 日志。
- 路线 A 文档留作考古，避免和本 ADR 抢叙述。

## 重新打开条件

- 若必须兼容某个无法语义迁移的第三方 ST 扩展，再评估只读适配器，而不是把 ST 请回宿主。
